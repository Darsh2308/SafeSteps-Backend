PROJECT GOAL
------------
Safe Steps AI V2 is an AI-powered emergency response system
that can operate in both online and offline environments.

The system prioritizes:

1. Immediate SOS delivery
2. Human emergency contact communication
3. Real-time threat detection
4. AI-assisted emergency intelligence
5. Multilingual support
6. Offline functionality

The AI must NEVER delay emergency SMS or emergency calls.

==========================================================
AUTHENTICATION
==========================================================

Flow:

Register (first time)
POST /auth/register
↓
Phone Number (unique login ID)
Full Name, Age, Gender, Blood Group,
Medical Notes, Preferred Language
↓
User ID generated (UUID — stored in MongoDB)
JWT Token issued
↓
User Profile returned

---

Login (returning user)
POST /auth/login
↓
Phone Number only
↓
JWT Token issued
User Profile returned

---

Rules:

- No OTP. No password. Phone number is the identity.
- Duplicate registration → 400 error.
- Unregistered login → 404 error.
- All protected endpoints require:
  Authorization: Bearer <token>

---

Profile Management:

GET  /auth/me         → Get own profile
PUT  /profile         → Update profile fields
POST /auth/logout     → Client discards token

COMPLETE AI STACK
==========================================================

ONLINE MODE (Backend — cloud APIs)
------------------------------------

Speech To Text:
- Sarvam STT (saaras:v1)
- Languages: en-IN, hi-IN, mr-IN

Intelligence:
- Primary:  Groq llama-3.1-8b-instant
- Fallback: Gemini 2.0 Flash

Text To Speech:
- Sarvam TTS (bulbul:v1)
- Returns WAV audio bytes
- Endpoint: POST /tts/synthesize


OFFLINE MODE (On-Device — mobile only)
----------------------------------------

Speech To Text:
- Faster Whisper Mobile
- Runs entirely on the Android device
- No API key required
- No internet required

Intelligence:
- Gemma 3n
- Runs entirely on the Android device
- No API key required
- No internet required

Text To Speech:
- Android Native TTS
- Built into Android OS
- No download required


NOTE: Offline AI models run ON THE DEVICE, not on the
backend server. The backend is not involved in offline mode.
The mobile app switches to local processing automatically
when internet is unavailable.


ALWAYS ACTIVE COMPONENTS (Backend)
------------------------------------

Voice Activity Detection:
- Silero VAD (ONNX model, runs in backend pipeline)
- Fallback: energy-based dBFS detection

Audio Event Detection:
- Keyword + dBFS based detection (v1 — backend)
- YAMNet + Custom Distress Detection Layer (planned v2)

Threat Engine:
- Threat Fusion Engine (backend)
- Combines: speech + audio events + GPS + call status

SHORT SUMMARY
==========================================================

Safe Steps AI V2 is an offline-capable, multilingual,
AI-powered emergency response system.

When SOS is triggered:

1.  GPS is acquired immediately.
2.  SMS is sent to 3 emergency contacts (with Maps link).
3.  Primary contact is called.
4.  Audio monitoring begins (WebSocket stream).
5.  Silero VAD detects speech.
6.  STT converts speech to text (Sarvam online / Whisper offline).
7.  Audio Event Detector listens for screams,
    crying, crashes and aggression.
8.  Threat Fusion Engine calculates risk level.
9.  Groq Llama (online) or Gemma (offline)
    generates emergency intelligence.
10. AI sends emergency updates and guidance via TTS.
11. Live tracking continues until the user
    marks themselves safe.
12. Session report auto-generated on close.
13. Safe SMS sent to all contacts.

The system works in:
- Cities
- Villages
- Poor Network Areas
- Completely Offline Environments

while supporting:
- English
- Hindi
- Marathi

and always prioritizes:
SMS → CALL → HUMAN HELP → AI ASSISTANCE
